PDF Manager

PDF Manager is a free Android app to view, organize, convert, print and repair PDF files. It can also convert Word, Excel and PowerPoint files to PDF.

To convert Office files, the app asks for permission to use your own Google Drive. It uses only the limited drive.file permission, so it can see only the temporary files it creates itself. Those files are deleted right after conversion.
